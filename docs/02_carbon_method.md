# 탄소 순감축 계산의 가정과 단위

보고서의 탄소 손익분기(전기 마을버스 약 44km/일, CNG 버스 약 104km/일)는 `evaluate_policy.py`와 `results/carbon_ev_summary.json`에서 재현됩니다. 아래는 계수 산정 근거와 1차 분석의 세부 가정입니다.

## 탄소 계산의 가정과 단위

일간 순감축 kgCO2 = 감소한 승용차 차량-km × 승용차 kgCO2/km - 추가 버스 차량-km × 버스 kgCO2/km.

공식 지침의 휘발유69,300kgCO2/TJ·30.1MJ/L, 천연가스56,100kgCO2/TJ·도시가스(LNG)38.5MJ/Nm3를 조합한다. 연료단위 계수는 각각2.08593kgCO2/L·2.15985kgCO2/Nm3이다. CNG에 도시가스 발열량을 적용하는 가정으로 실제 가스 성상·표준체적 확인이 필요하다. 현행 2025-10-07 지침에 연결된 별표4를 출처로 사용한다.

승용차10km/L·가상 CNG버스2km/Nm3·추가버스20km/일·연250일은 모두 관측값이 아닌 가정이다. 실제 3411번의 연료·연비나 예상 수요를 뜻하지 않는다. 기본 손익분기는 승용차103.543743km/일 감소이며 이를 초과해야 순감축이다. 감소거리80·200·400km/일 가정 시 연간 순감축은 -1.23·5.03·15.46tCO2이다. 음수는 배출 증가다. 연비 민감도는 승용차8~15km/L·버스1.5~3km/Nm3라는 연구자 설정 범위에서55.22~207.09km/일이다.

추가 버스 거리는 증회·우회·공차·회송을 포함해야 한다. 버스 추가0km 조건은 일정한 km당 연료소비를 두는 단순모형이며 승객 무게·정체·공회전 변화까지0이라고 실측한 결과가 아니다. 신규 외출, 보행·철도에서의 전환, 승객 수를 승용차 차량-km 감소로 계산하지 않는다. CH4·N2O·연료 상류·차량 제조·보행시설 공사는 제외하므로 전과정 온실가스 감축이나 CO2e로 부르지 않는다. 이동권 개선 편익은 탄소 평가와 별도로 판단한다.

추가 원자료는 `python fetch_policy_data.py`로 재수집할 수 있다. 파일 기준일·온라인 갱신에 따라 원자료가 달라질 수 있으며 기본 분석은 동봉 스냅샷으로 재현한다.
